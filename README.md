# Shanvi Constructions

Marketing site for Shanvi Constructions, built with Next.js (App Router) and TypeScript.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

- `app/` — root layout, page and global styles
- `components/` — one component per page section
- `lib/data.ts` — site content (principles, stages, projects, materials)
- `public/images/` — photography and logos
